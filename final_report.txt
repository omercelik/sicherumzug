# AI-First & SEO-First Technical Architecture Update

## 1. Information Architecture & Scalability
- **Action:** Created `_data/locations.yml` and a reusable `_includes/location-list.html`.
- **Reason:** Prepares the scalable foundation for the requested "State → City → Service" structure without prematurely exposing empty or duplicate pages.
- **Action:** Removed hardcoded `# Title` tags from markdown guide files.
- **Reason:** Fixes duplicate H1 tag errors, as the `_layouts/guide.html` and `_layouts/page.html` automatically generate the H1 based on the frontmatter title.

## 2. Technical SEO & Hreflang
- **Action:** Updated `_config.yml` to define `lang: de-AT`.
- **Reason:** Establishes the clear local entity target (Austria).
- **Action:** Modified `_includes/meta_tags.html` to output `hreflang` tags (de-AT, de, x-default).
- **Reason:** Eliminates geographical ambiguity for search engine crawlers.

## 3. HTML5 Semantic & Accessibility Upgrades
- **Action:** Upgraded structure in `_layouts/default.html`, `page.html`, `service.html`, `guide.html`, and `service-index.html`.
- **Reason:** Replaced generic `div`s with `<main role="main">`, `<article role="document">`, etc., maximizing machine readability and AI contextual parsing.
- **Action:** Upgraded Javascript `mobileMenuToggle` in `assets/js/site.js`.
- **Reason:** Dynamically toggles `aria-expanded` and `aria-controls`, resolving critical WCAG focus/screen-reader barriers.
- **Action:** Added explicit `width` and `height` and `loading="eager"` attributes to Hero images.
- **Reason:** Prevents CLS (Cumulative Layout Shift) and optimizes LCP.

## 4. Schema.org Entity Graph Refactoring
- **Action:** Rewrote JSON-LD logic in `_includes/seo.html`.
- **Reason:** Shifted from nested, disconnected schemas to a unified graph architecture using `@id`. Now, `Organization`, `WebSite`, `WebPage`, `LocalBusiness`, `Service`, `FAQPage`, and `Article` are explicitly interlinked.
- **Action:** Checked `sameAs` array logic.
- **Reason:** Ensured only verified social profiles from `_config.yml` are output, preventing hallucinatory authority links.

## 5. EEAT & Content Helpfulness
- **Action:** Activated `use_global_faqs: true` in core pages (`leistungen.md`, `ueber-uns.md`, `ablauf.md`, `preise.md`) and injected missing FAQ schema generation logic into their layouts.
- **Reason:** Answers real user intent questions naturally on high-value pages, structurally validating the business expertise (EEAT).
